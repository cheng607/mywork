# 3D mascot model

Place the exported, textured GLB here as `cheng607-mascot.glb`.

The portfolio loads this file from `index.html` when it exists. Use a web-ready GLB with compressed geometry and 1K–2K textures. Embedded animation clip names should include recognizable words such as `idle`, `wave`, `point` or `think` for the matching section actions.

This repository is published as a public portfolio. Confirm the model's license and required attribution before adding the file.
